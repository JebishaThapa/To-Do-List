# To-Do List App

This repository contains a simple, responsive To-Do List application built with JavaScript, HTML5, and CSS3.

I built this project to practice dynamic DOM manipulation, event handling, and persisting application state in the browser.

_______________________________________________________________________________________________________________________________________________________________________________________________________________________________________________________________________________________________

WHAT'S INSIDE

The application is structured into three clean core files:

* `index.html` defines the structural layout and input elements.
* `style.css` provides custom styling, linear gradient backgrounds, and visual toggle states.
* `script.js` powers the application logic, event listeners, and local storage persistence.

---

WHAT I AM LEARNING

Key web development concepts implemented in this project include:

* Dynamic element creation (`document.createElement`) and DOM insertion (`appendChild`).
* Event delegation via click targets (`e.target.tagName`) to manage item completion and deletion.
* State persistence using `localStorage` (`setItem` and `getItem`) so tasks remain saved after browser refreshes.
* Form validation to prevent adding empty input tasks.
* CSS class toggling (`classList.toggle`) for UI feedback like strikethroughs.



WHY THIS EXISTS

I'm keeping this repository public as part of my frontend journey, documenting how I handle state management and DOM interactions before moving on to larger web applications.

The goal is simple: learn by building, make mistakes, figure them out, and gradually write better code.
